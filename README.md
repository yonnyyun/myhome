# 온집 — 우리 집 돈의 흐름

월별 가용자금·수입·소비를 한눈에 보고, 월간 적자와 자금 소진 시점을 확인하는 모바일 웹사이트입니다.

## 기능
- 월별 가용금액, 수입·소비 합계, 카테고리별 소비와 최근 거래
- 거래 직접 등록·수정·삭제, 유형·카테고리 필터와 검색
- 고정지출 계획과 납부 등록, 예정 지출 중복 방지
- 월 변동지출 시나리오, 24개월 예측, 목표 월까지의 생활비 한도
- 거래 스크린샷 한글 OCR → 후보 검토·수정 후 개별 저장
- JSON 백업·복원

## 로컬 실행
설치나 빌드 없이 실행할 수 있습니다. 저장소 폴더에서:

```sh
python3 -m http.server 5173
```

브라우저에서 http://localhost:5173 을 여세요. 첫 화면에는 예시 데이터가 표시됩니다. 실제 사용은 설정 → 전체 비우고 시작 → 기준 잔액과 수입·지출 계획 설정 순서로 진행하세요.

## Netlify 배포
Netlify에서 **Add new project → Import an existing project → GitHub → yonnyyun/myhome**을 선택하세요.

- Build command: 비워두기
- Publish directory: `.`
- `netlify.toml`에 게시 경로를 포함했습니다.

사이트에 설정된 배포 브랜치에 변경 내용을 push하면 Netlify가 새 버전을 배포합니다. GitHub에 올리는 작업만으로 웹사이트가 자동으로 게시되지는 않습니다. Netlify 연결과 첫 배포가 필요합니다.

## 데이터와 예측
현재는 localStorage에 저장합니다. 서버 DB·로그인·가족 공유·기기 간 자동 동기화는 포함하지 않습니다. 브라우저 저장소를 삭제하면 내역이 지워지므로 JSON 백업을 보관하세요.

기준일부터 오늘까지의 실제 거래로 현재 잔액을 계산하고, 앞으로의 월 수입·변동지출·미납 고정지출 계획으로 월말 잔액을 예측합니다. 월중 입출금 순서는 반영하지 않습니다. 자세한 계산과 후속 개발 범위는 [PRD](docs/PRD.md)를 참고하세요.

## 디자인과 외부 리소스
흰색 카드, 옅은 블루·라일락·민트 그라디언트, 검정 알약형 CTA, Pretendard 가변 폰트를 사용합니다. Pretendard와 OFL 라이선스는 `fonts/`에 포함했습니다.

OCR은 Tesseract.js를 CDN에서 내려받아 브라우저에서 이미지를 분석합니다. 인터넷 연결이 필요하며 이미지 원본은 서버에 저장하지 않습니다. 인식 결과는 직접 확인한 뒤 저장하세요.

## 파일
- `index.html` — 화면과 입력 폼
- `style.css` — 반응형 디자인
- `app.js` — 거래·고정지출·예측·백업·OCR
- `fonts/` — Pretendard와 라이선스
- `docs/PRD.md` — 제품 요구사항
- `netlify.toml` — 정적 사이트 게시 설정

## 검증
JavaScript 문법 검사와 잔액·월간 적자·고정지출 중복 방지·미래 수입·월말 납부일 계산 검증을 통과했습니다. 모바일 360px 등록 폼과 데스크톱 1280px 내역 화면을 확인했습니다. OCR의 실제 이미지별 정확도는 별도 검토가 필요합니다.
