# 온집 — 우리 집 돈의 흐름 PRD

작성일: 2026-10-21 · 버전: 1.0 · 모바일 우선 MVP

## 1. 문제와 목표
특정 시점까지 사용할 수 있는 가계 자금이 제한되어 있지만 현재 잔액, 월 소비와 수입, 앞으로의 지출을 함께 보기 어렵다. 월간 적자와 자금 소진을 구분하고 소비 계획을 조절할 근거를 제공한다.

사용자가 홈에서 10초 안에 다음 질문에 답할 수 있어야 한다.
- 지금 쓸 수 있는 돈은 얼마인가?
- 이번 달 얼마를 벌고 썼는가? 월간 적자는 얼마인가?
- 곧 내야 할 고정지출은 무엇인가?
- 매월 이 정도 소비하면 언제 자금이 부족해지는가?
- 목표 월까지 버티려면 월 생활비를 얼마로 제한해야 하는가?

## 2. 대상과 가정
가계 자금의 사용 가능 기간을 관리하는 가구의 주 관리자가 대상이다. 통화는 원화, 기준 시간대는 한국이다. 계좌 여러 개를 직접 연동하는 대신 합산 기준 잔액을 입력한다. 신용카드 사용 내역을 소비로 등록했다면 카드대금 출금을 다시 소비로 등록하지 않는다. 계좌 간 이체도 수입·소비로 중복 입력하지 않는다.

초기 제공물은 실제 동작하는 브라우저 저장형 MVP다. 서버 저장, 가족 계정 공유, 은행·카드 연결, 푸시 알림은 후속 범위다. 예시 데이터는 명시적으로 표시하고 전체 비우기로 제거할 수 있다.

## 3. 화면과 핵심 흐름
### 홈 / 한눈에 보기
- 월 이동, 현재 가용금액, 선택 월 실제 소비·수입, 월간 잉여 또는 적자.
- 향후 9개월 월말 잔액 그래프와 24개월 범위의 자금 부족 경고.
- 월 고정지출 합계, 등록된 납부액, 다가오는 고정지출 3건.
- 카테고리 소비 비중, 최근 거래, 내역 등록 진입.
- 현재 월의 잔액은 오늘까지 등록한 거래만 반영한다. 다른 월은 해당 월 말까지 등록한 거래를 반영한다. 미래 월의 잔액도 등록 내역 기준이며 예측 그래프와 구분한다.

### 월별 수입·소비 내역
- 월별 리스트와 합계, 소비·수입 필터, 카테고리 필터, 이름 검색.
- 거래를 눌러 금액·날짜·카테고리·이름·메모 수정 및 삭제.
- 고정지출에 연결된 소비는 별도 배지로 표시한다.

### 직접 등록
유형 선택 → 이름·금액·날짜·카테고리 입력 → 고정지출 연결(선택) → 저장 → 합계와 예측 갱신.
금액은 양의 정수다. 고정지출 연결은 소비에만 허용하며 같은 달 같은 고정지출에 중복 연결할 수 없다.

### 스크린샷 등록
PNG/JPG/WEBP 한 장(10MB 이하) 선택 → 브라우저 OCR → 인식 텍스트 확인·수정 → 거래 후보 → 후보별 상세 검토·수정 → 저장.
- Tesseract.js 한글·영문 인식 엔진을 CDN에서 로딩한다. 이미지 원본을 서버에 업로드하거나 보관하지 않는다.
- 날짜·금액·상호를 휴리스틱으로 추출하며 OCR 결과의 정확성을 보장하지 않는다. 잔액·계좌번호 등으로 보이는 줄은 후보에서 제외한다.
- 여러 합계가 있는 영수증은 중복 후보가 생길 수 있으므로 자동 확정하지 않는다. 최대 30개 후보를 보여준다.
- 각 후보를 개별 저장한다. 인식 실패 시 텍스트 붙여넣기 또는 직접 등록이 가능하다.

### 고정지출 관리
이름·월 금액·납부일(1~31일)을 추가하고 삭제할 수 있다. 29~31일이 없는 달에는 말일을 적용한다. 이번 달 납부 등록은 실제 거래 생성 폼으로 이어지며 사용자 저장 후 잔액에 반영한다. 계획만 등록하면 실제 잔액은 줄어들지 않는다. 삭제 시 기존 거래는 일반 소비로 유지한다. 금액·날짜 변경은 항목 재등록으로 처리한다.

### 자금 시뮬레이션
월 변동지출 슬라이더·숫자 입력, 월 총 예상 소비, 수입, 자금 부족 월, 월간 적자 시작 월과 금액, 24개월 월별 수입·소비·잔액 표. 설정한 목표 월까지 유지 가능한 균등 월 변동지출 상한을 제공한다. 슬라이더 변경은 월 변동지출 계획에 저장한다.

### 설정 / 데이터 관리
기준일과 기준일 시작 잔액, 예상 월 수입, 월 변동지출, 목표 월(현재부터 최대 120개월)을 설정한다. JSON 백업 내보내기·복원, 전체 초기화를 제공한다. 복원은 형식·범위·중복 ID 검증 후 현재 데이터를 교체한다.

## 4. 계산 정의
가용금액 = 기준일 시작 잔액 + 기준일부터 조회일까지 실제 등록 수입 − 실제 등록 소비.
월간 잉여·적자 = 해당 월 등록 수입 − 등록 소비. 음수이면 월간 적자다. 미래의 예정 거래도 등록했다면 해당 월 합계에는 포함된다.

예측은 오늘 가용잔액에서 시작한다. 이번 달의 미래 날짜 등록 거래는 이번 달 말 반영한다.
- 월 예상 수입 = max(해당 월 등록 수입, 설정 월 수입).
- 등록 변동지출 = 고정지출에 연결되지 않은 소비 합계.
- 월 예상 소비 = 등록 소비 + max(0, 설정 월 변동지출 − 등록 변동지출) + 아직 납부 등록하지 않은 고정지출 합계.
- 현재 월의 잔액 계산에는 이미 오늘까지 반영한 실제 거래를 중복 반영하지 않는다.
- 미래 월말 잔액 = 이전 월말 잔액 + 월 예상 수입 − 월 예상 소비.
- 최초 월간 적자 월 = 예상 소비가 예상 수입보다 큰 최초 월.
- 전액 소진 = 월말 잔액이 0원, 자금 부족 시작 = 월말 잔액이 음수인 최초 월. 현재 잔액이 음수면 이미 부족한 것으로 표시한다.
- 소진·부족은 월 단위 추정이다. 월중 입출금 순서, 수입 변동, 이자·물가·투자는 반영하지 않는다.

목표 월까지의 월 변동지출 상한은 동일한 월별 예측 함수를 사용해 계산한다. 현재부터 목표 월까지 모든 월말 잔액이 0원 이상인 최대 월 변동지출을 이분 탐색으로 구하고 만원 단위로 내림 표시한다. 이미 등록된 미래 거래도 반영한다. 변동지출 0원으로도 목표 유지가 불가능하면 수입·고정지출 조정이 필요하다고 안내한다.

## 5. 데이터 모델
- Settings: start(기준일), balance(기준 잔액), income(월 예상 수입), variable(월 변동지출), target(목표 월).
- Transaction: id, type(expense/income), name, amount, date, category, memo, fixedId(선택).
- FixedExpense: id, name, amount, day.
- Storage: localStorage 키 onjip-v1. 이미지와 OCR 결과는 지속 저장하지 않으며 사용자가 확정한 거래만 저장한다.

## 6. 비기능 요구사항
- 360px 이상 모바일과 데스크톱 반응형. 모바일 하단 내비게이션, 폼 레이블, 키보드 포커스, 모달 제공.
- 사용자 문자열 HTML 이스케이프, 금액·날짜 폼 검증, 백업 파일 구조 검증.
- 데이터는 현재 브라우저에만 저장된다. 다른 기기·브라우저·가족 간 동기화는 없다.
- 브라우저 데이터 삭제에 대비해 JSON 백업을 제공한다.
- Pretendard 가변 폰트를 사이트 파일에 포함한다. 폰트 로딩 실패 시 시스템 폰트를 사용한다. OCR 엔진 다운로드에는 인터넷이 필요하며 실패 시 텍스트 입력으로 대체한다.
- 호스팅은 소유자 비공개로 배포한다. 가족 공유가 필요하면 서버 저장 및 사용자별 권한 설계부터 추가한다.

## 7. 수용 기준 / 검증
1. 잔액 1,000만원, 수입 300만원, 지출 400만원이면 월 적자 100만원이며 잔액은 900만원이다.
2. 고정지출 계획만 추가하면 실제 잔액이 변하지 않고 예측만 변한다.
3. 같은 달 고정지출을 납부 등록하면 실제 소비가 늘고 예정 고정지출에서 빠져 중복 합산하지 않는다.
4. 거래 수정·삭제·새로고침 이후 합계와 저장 내역이 일치한다.
5. 월 변동지출 변경 시 그래프·부족 시점·월별 표가 함께 변경된다.
6. OCR 후보는 사용자 저장 전에는 실제 거래가 되지 않는다. 인식 실패도 직접 입력으로 완료할 수 있다.
7. 데이터 없음, 무수입, 월 잉여, 이미 음수인 잔액, 월말 납부일을 처리한다.
8. JSON 백업 복원은 유효하지 않은 데이터와 중복 ID를 거부한다.

## 8. 후속 개발
P1: 서버 DB, 로그인, 가족 공동 가계부와 권한, 데이터 변경 이력, 고정지출 편집·납부 누락 안내.
P2: 카드·은행 자동 연동, 여러 스크린샷 일괄 검토, 정교한 OCR 필드 인식 및 중복 거래 탐지, 일별 현금흐름과 부족일 예측.
P3: 예산 알림, 반복 수입, 카테고리별 목표, 부부 구성원별 통계.

출시 후 지표: 기준 잔액·목표 월 설정 완료율, 첫 거래 등록 완료율, OCR 후보 수정·저장률, 주간 재방문율, 시뮬레이션 사용률. 현재 MVP에는 사용자 추적을 넣지 않는다.
